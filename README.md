# E-Shop

Sistema de comercio electrónico desarrollado como proyecto académico.

## Requisitos

Antes de comenzar, asegúrate de tener instalado:

- Git
- El entorno de desarrollo correspondiente al proyecto
- Un editor de código como Visual Studio Code

## Instalación

### 1. Clonar el repositorio

Usando SSH:

```bash
git clone git@github.com:domenicadas/e-shop.git
```

### 2. Ingresar al directorio del proyecto

```bash
cd e-shop
```

### 3. Instalar las dependencias

Ejecuta el comando correspondiente según la tecnología del proyecto.

**Si es Python**

```bash
pip install -r requirements.txt
```

**Si es Node.js**

```bash
npm install
```

### 4. Configurar variables de entorno (si aplica)

Crear un archivo `.env` en la raíz del proyecto y agregar las variables necesarias.

Ejemplo:

```env
API_KEY=tu_api_key
DATABASE_URL=tu_base_de_datos
```

### 5. Ejecutar la aplicación

Dependiendo de la tecnología utilizada:

**Python**

```bash
python main.py
```

**Node.js**

```bash
npm start
```

o

```bash
npm run dev
```

## Contribuciones

1. Haz un Fork del repositorio.
2. Crea una rama para tu funcionalidad.

```bash
git checkout -b feature/nueva-funcionalidad
```

3. Realiza tus cambios y confirma los commits.

```bash
git commit -m "Descripción de los cambios"
```

4. Envía los cambios a tu repositorio.

```bash
git push origin feature/nueva-funcionalidad
```

5. Abre un Pull Request.
